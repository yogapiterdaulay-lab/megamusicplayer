# Roompi website — GitHub Pages

Upload the **contents** of this folder to the root of your GitHub Pages repository.

- `https://roompi.my.id/` — Roompi homepage (`index.html`)
- `https://roompi.my.id/szstudio/` — SZ Studio (`szstudio/index.html`)
- `https://roompi.my.id/szstudio/megamusic/` — Mega Music placeholder (`szstudio/megamusic/index.html`)
- `https://roompi.my.id/sasa-paint.html` — Sasa Paint placeholder

Clicking the Mega Music logo within SZ Studio opens the nested Mega Music route. The Google Play badge remains linked to the external testing page. The old root `mega-music.html` redirects to the new route for compatibility.

The `CNAME` file sets the GitHub Pages domain to `roompi.my.id`; DNS and Pages settings must be configured separately.
